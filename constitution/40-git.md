# Git и окружение

## Коммиты

- Commit агенту **разрешён**; `git push` и создание MR — **запрещены**, это делает только
  пользователь.
- Автор коммита — личность из `git config`; трейлер `Co-Authored-By` не добавляется.
  Не менять `user.name`/`user.email`, не использовать `--author`.
- Один коммит — одно логическое изменение. TDD-порядок: тестовый коммит раньше реализации.
- **Никогда** `git add .` / `git add -A` — только явные пути. В рабочем дереве могут быть
  чужие staged/modified файлы: не коммитить, не откатывать, не анстейджить их.
- Перед коммитом кода — зелёный `make test`, `make lint`, `make arch`.

## Зависимости

- Новые сторонние зависимости — только по явному решению пользователя.

## Инструменты

- `make test` - запустить тесты
- `make lint` - запустить линтер с конфигом в корне
- `make arch` - проверить архитектуру проекта на соответствие правилам
